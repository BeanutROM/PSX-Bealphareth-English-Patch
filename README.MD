# Bealphareth English Patch

An English translation patch for the Japanese PSX release of **Bealphareth**.
You need your own Japanese game bin/cue set as no game files or copyrighted work is distributed here,

This was translated with the assistance of OpenAI Codex as directed to for any and all work by a human.
The text was reviewed and edited by a human where necessary.

All found dialog, UI, and FMV text is translated.

This has been thoroughly tested on Duckstation and a MiSTer FPGA system to completion. Not every scene has been examind however, as there are multitudes of character specific interactions, and with a dozen characters that can be in any combination of two with you at a time, there's quite a few small scenes that haven't been verified -- but I have no reason to expect there's anything wrong with them.


## Patching manually

Apply the xdelta patch to its original bin file.
